# Complete E-Commerce Frontend Application

## Project Overview
This project is a **responsive React E-Commerce frontend application**.
It includes product listing, shopping cart, simulated user authentication, and checkout process.
The application demonstrates frontend concepts such as component hierarchy, state management, API integration, and routing.

---

## Objectives
- Build a fully functional e-commerce frontend
- Fetch products from external API
- Implement cart state management using Context API
- Use React Router for modern navigation
- Create responsive UI

---

## Technologies Used
- React.js
- React Router
- Context API
- CSS3 (responsive styling)
- FakeStoreAPI (for demo product data)

---

## Features Implemented
- Product listing from FakeStoreAPI
- Shopping cart with add/remove functionality
- Routing between Home and Cart pages
- Responsive layout
- Component-based architecture
